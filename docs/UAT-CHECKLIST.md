# 학교 PC 수동 UAT 체크리스트 (Phase 5-B)

> 작성: 2026-11-04 / 대상 빌드: 배포 후보 `0.3.0-rc.1` / **미수행** — 실행 결과는 `docs/UAT-RESULT-TEMPLATE.md` 사본에 기록한다.

## 0. 이 문서의 상태
**이 체크리스트는 아직 수행하지 않았다.** 어떤 항목도 통과로 기록되어 있지 않으며, 실제 Windows·학교 PC·실제 Excel 에서 수행한 결과가 나오기 전까지 모든 항목은 미검증이다.
자동 테스트와 CI 통과는 이 체크리스트의 대체가 아니다.

## 1. 데이터 취급 규칙 (반드시 지킨다)
- **실제 재단 자료는 로컬 PC 에서만 사용한다.** 외부로 보내지 않는다: 업로드, 메일·메신저 첨부, AI 도구에 붙여넣기, 클라우드 문서에 올리기 모두 금지(`docs/PUBLIC-SAFETY.md`). 이 저장소(공개)에도 올리지 않는다.
- 합성 자료(CI 아티팩트 `…e2e-synthetic-outputs…`, `tools/synthetic`)로 먼저 연습한 뒤 실제 자료로 한다.
- **결과 기록에 쓰지 않는 것**: 학생 이름, 학번, 계좌번호, 실제 파일 이름(원본·결과·템플릿·정책), 금액·인원·합계 같은 수치와 파생 통계(종류 수·분포 포함), 경로 전체(사용자 이름이 들어 있다).
- 쓸 수 있는 것: 항목 번호, 일치/불일치 여부, 시트·열 이름 같은 위치 유형, 오류 코드(예: DUPLICATE_STUDENT_ID), 행 번호, 환경 범주(Windows 버전, Excel 버전, 배율, 해상도, 경로 유형: 로컬/네트워크/OneDrive), 소요 시간(대략 초).
- **스크린샷**: 학생 정보·실제 경로·실제 파일 이름이 보이는 화면은 찍지 않는다. 필요하면 합성 자료로 같은 화면을 다시 만들어 찍는다.
- 채워진 결과 양식은 저장소에 커밋하지 않고 `private/uat/`(git 무시 폴더) 또는 학교가 정한 안전한 위치에만 둔다.

## 2. 준비물
- 시험할 빌드: CI 아티팩트 `ScholarshipPayment-v0.3.0-rc.1-<커밋7자리>` (SHA256SUMS.txt 로 무결성 확인). 되돌리기 시험용으로 `ScholarshipPaymentLegacyTk-…` 도 받는다.
- 정책(.json)·학교 출력 템플릿(.xlsx)은 프로그램에 들어 있지 않다. 담당자에게서 받는다.
- 시험 PC: 서로 다른 Windows·Excel 버전 2대 이상(권장), 일반 사용자 계정, Python 미설치. 가능하면 1366×768 해상도 PC 1대.
- 빈 시험 저장 폴더(결과를 모으지 않는 폴더)와 연습용 합성 원본.

## 3. 판정과 결함 등급
- 판정: 통과 / 실패 / 해당 없음 / **미검증**(수행하지 않음). 일부만 수행했으면 미검증으로 두고 메모에 범위를 쓴다.
- 결함 등급: **P0**(데이터 정확성 오류·잘못된 파일 생성·개인정보 노출·덮어쓰기·실행 불가) / **P1**(핵심 기능이 안 되거나 우회가 어려움) / **P2**(불편·표시 문제, 우회 가능) / **P3**(사소한 문구·외관).
- **중단 조건**: P0 가 하나라도 나오면 해당 시험을 멈추고 배포 불가로 본다. 원인 수정과 재검증 전에는 다음 단계로 가지 않는다.
- 배포 가능 여부의 판정 기준은 `docs/RELEASE-RC1.md` §6 이 정한다. 이 체크리스트의 통과는 그 필수 조건 중 일부일 뿐이다.

## 4. 항목
항목 번호(U01…)는 결과 양식(`docs/UAT-RESULT-TEMPLATE.md`)의 행과 같다. 각 항목의 `[P0..P3]`는 이 항목이 실패했을 때 예상되는 결함 등급이다.

### U01 Windows 실제 창 실행 [P0]
- **목적**: 실제 Windows에서 창이 정상 표시되고 글꼴·제목이 올바른지 확인한다.
- **절차**:
  1. 압축을 푼 폴더에서 ScholarshipPayment-v…exe 를 실행한다(관리자 권한 아님).
  2. 창 제목에 버전(0.3.0-rc.1)이 보이는지, 글꼴이 맑은 고딕 계열로 보이는지 확인한다.
  3. 창 이동·크기 조정·최소화·복원을 해 본다. 실행까지 걸린 시간을 대략 기록한다(초 단위).
- **기대 결과**: 창이 나타나고 글자 깨짐·잘림이 없다. 제목 표시줄은 Windows 기본이다. 단계 표시(파일 선택 › 지급내역 확인 › 결과 생성)가 보인다.
- **기록**: 결과 양식 U01 행(판정, 결함 등급, 메모). 학생 정보·실제 파일 이름·수치는 쓰지 않는다.

- **기대 결과**: 엑셀(.xlsx)/정책(.json) 필터가 동작하고, 취소하면 아무것도 바뀌지 않는다. 한글·공백 경로가 정상 처리된다.

### U08 설정 저장과 복원 [P0]
- **목적**: 고급 설정과 사용자 설정 파일의 저장·복원·손상 복구를 확인한다.
- **절차**:
  1. 고급 설정에서 사업별 템플릿·정책·기본 저장 폴더를 지정하고 '설정 저장 및 적용'을 누른다.
  2. 프로그램을 닫고 다시 실행해 값이 복원되는지, 사업을 바꿔도 값이 섞이지 않는지 본다.
  3. 설정 창에서 '취소'로 닫으면 아무것도 바뀌지 않는지 본다.
  4. %APPDATA%\ScholarshipPayment 폴더에 settings.json 이 생겼는지 확인한다(내용은 기록하지 않는다).
  5. 프로그램을 닫고 settings.json 을 일부러 망가뜨린 뒤 다시 실행한다.
- **기대 결과**: 값이 복원되고 사업별로 독립이다. 손상된 파일은 settings.json.bak 으로 보존되고 기본값으로 시작하며 안내가 보인다. 원본 파일 경로·비밀번호·기준일은 저장되지 않는다.
- **기록**: 결과 양식 U08 행(판정, 결함 등급, 메모). 학생 정보·실제 파일 이름·수치는 쓰지 않는다.

### U09 대청교 변환 [P0]
- **목적**: 실제 대청교 원본(로컬에서만 사용)으로 세 단계를 끝까지 수행한다.
- **절차**:
  1. Step 1 에서 사업·원본·저장 폴더를 고른다.
  2. Step 2 에서 미리보기를 확인한다(U13 과 함께).
  3. Step 3 에서 '지급명단 생성'을 누르고 결과 파일을 연다.
  4. 이월(한 학생 2행) 사례가 있다면 한 명으로 합산되는지 본다.
  5. 기존 방식(수작업 또는 이전 버전)으로 만든 승인된 결과와 항목 단위로 대조한다.
- **기대 결과**: 생성이 성공하고 '출력 재검증 통과'가 표시된다. 세 시트의 대상자 수·금액이 승인된 결과와 같다. 불일치가 있으면 위치 유형(시트·열 이름)만 기록한다.
- **기록**: 결과 양식 U09 행(판정, 결함 등급, 메모). 학생 정보·실제 파일 이름·수치는 쓰지 않는다.

  3. 사업자등록번호 열(F)이 공란이고 숨김인지 확인한다.

### U12 암호 파일 처리 [P0]
- **목적**: 암호가 걸린 원본의 비밀번호 흐름을 확인한다.
- **절차**:
  1. 암호가 걸린 원본을 선택하고 Step 2 로 이동한다.
  2. 일부러 틀린 비밀번호를 입력한다. 3번 틀려 잠기는지, 취소했다가 다시 입력할 수 있는지 확인한다.
  3. 맞는 비밀번호로 미리보기와 생성을 끝낸다.
  4. 설정 파일·결과 파일·화면 어디에도 비밀번호가 남지 않았는지 확인한다.
- **기대 결과**: 비밀번호는 필요할 때만 묻고, 최대 3번까지 받는다. 입력창은 제출 즉시 비워진다. 어느 곳에도 비밀번호가 남지 않는다.
- **기록**: 결과 양식 U12 행(판정, 결함 등급, 메모). 학생 정보·실제 파일 이름·수치는 쓰지 않는다.

### U13 지급내역 미리보기 [P0]
- **목적**: Step 2 의 읽기 전용 미리보기가 원본과 맞는지 확인한다.
- **절차**:
  1. 지급연월·대상자 수·금액 합계가 원본의 합계 행 또는 승인된 수치와 같은지 대조한다(값은 기록하지 않고 일치/불일치만).
  2. 오류·경고·참고가 구분되어 보이고 한국어 설명과 조치 안내가 있는지 확인한다.
  3. 미리보기 동안 저장 폴더에 새 파일이 생기지 않았는지 확인한다.
- **기대 결과**: 수치가 일치하고 오류·경고·참고가 구분된다. '확인한 것 / 아직 확인하지 않은 것'이 구분되어 표시된다. 미리보기는 파일을 만들지 않는다.
- **기록**: 결과 양식 U13 행(판정, 결함 등급, 메모). 학생 정보·실제 파일 이름·수치는 쓰지 않는다.

### U14 파일 변경 감지 [P0]
