# 학교 PC UAT 결과 기록 양식

> 이 파일은 **빈 양식**이다. 사본을 `private/uat/` 에 만들어 채우고, 채운 사본을 저장소에 커밋하거나 외부로 보내지 않는다. 수행하지 않은 항목은 **미검증**으로 남긴다.
> 쓰지 않는 것: 학생 이름, 학번, 계좌번호, 실제 파일 이름, 금액·인원·합계 같은 수치와 파생 통계, 경로 전체(사용자 이름 포함), 비밀번호. 학교 시스템 계정 정보도 적지 않는다. 채운 결과는 저장소에 올리지 않는다.
