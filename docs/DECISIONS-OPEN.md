# 결정 사항과 미확정 사항

> 결정은 사용자가 내린 것만 적는다. 샘플·실측으로 알게 된 사실은 `FILE-STRUCTURE.md`, 미확정은 `OPEN-QUESTIONS.md`(근거·영향도 포함)에서 관리한다.

## A. 확정된 결정
### 제품·범위
- Windows 사용자용 오프라인 데스크톱 실행파일. macOS + Claude Code로 개발, Windows에서 빌드·실검증.
- 사업 3개(대청교 / 다문화·탈북학생 멘토링 / AI멘토링). 표준 출력 서식은 단일. 미제공 양식은 추정하지 않으며 **다문화·AI멘토링 Adapter는 실제 샘플 확보 전까지 구현하지 않는다.**
- 필수 출력 시트 3개(`지급대상자명단(해당 월)`, `WINS`, `WRIS`) + `은행코드` 참조 시트. `wins 업로드 결과(2.9)`는 기본 제외. 결과는 다중 시트 1개 파일.
- 대상자 수는 고정하지 않는다. **1명부터 120명 이상**을 지원한다.
- 기존 지급명단의 셀 스타일, 병합, 수식, 행 높이, 열 너비, 인쇄 설정을 **최대한** 보존한다.
- 원본 입력 파일을 변경하지 않고, 기존 출력 파일을 무단으로 덮어쓰지 않는다.

### 데이터 처리
- 내부 학번·계좌번호는 **문자열**로 처리한다. (출력 셀 타입은 템플릿·업로드 시스템 요구에 맞춰 별도 결정 → OPEN-QUESTIONS)
- 지급금액은 **재단 승인금액**(입력 `재단 장학금 계`)을 기준으로 한다. 금액은 정수 원 단위.
- 활동시간은 내부에서 **분 단위 정수**로 처리하고 출력 형식에 맞춰 변환한다.
- 은행코드는 출력 시스템별(WINS용, WRIS용)로 **개별 변환**한다. 지급 대상자의 필요한 은행코드가 없거나 모호하면 **지급명단 생성을 차단**한다.
- 입력의 `A`, `B`, `V`, `W`, `X`열은 의미 확인 전까지 **지급 대상자 필터 조건으로 사용하지 않는다.**

### 공개 저장소 [결정]
- 이 프로젝트는 **GitHub Public 저장소**로 공개한다. 실제 업무자료와 공개용 테스트 데이터를 엄격히 분리한다(`PUBLIC-SAFETY.md`).
- 기존 마스킹 파일은 공개 안전성이 확인되지 않았으므로 **커밋하지 않는다.** 테스트용 엑셀은 완전 합성(학생·기관·금액) 데이터로 별도 생성한다.
- 설계 문서에도 실제 기관정보, 내부 시스템 식별값, 업무자료에서 추출한 값을 쓰지 않는다. 저장소에는 공개 가능한 코드·문서·합성 템플릿만 포함한다.

### 방향(우선 검토, 최종 확정 아님)
- WINS·WRIS는 수식 대신 **실제 값 기록**을 우선 검토한다. 전산 업로드 호환성 검증 전에는 확정하지 않는다.

## B. 아직 확정되지 않은 것
`OPEN-QUESTIONS.md`를 본다. 대표 항목: 업로드 호환성(수식 vs 값), 출력 학번 셀 타입, 사업별 상수(근로구분명·구분코드 2종·적요), 예금주 정책, 중복 학번, 0원·취소·음수 행, `Q2` 기준일, 0명 정책, 학교 PC 보안정책.

## C. 이전 문서 대비 변경
- 이전 "미확정 6번(금액 출처)", "미확정 10번(빈 코드 허용 여부)"은 A에서 결정됨(승인금액 기준, 필요한 코드 없으면 차단).
- 이전 "지급 대상자 필터" 관련 해석 여지는 A로 닫음(A/B/V/W/X 미사용).
