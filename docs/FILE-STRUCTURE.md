# 마스킹 샘플의 구조 (1개월분) — 실측 기준

> 근거: `samples/`의 마스킹 xlsx 2개를 (1) Python 표준 라이브러리(zip+XML), (2) openpyxl 3.1.5로 **읽기 전용** 분석했다. 원본은 수정·저장하지 않았고 SHA-256 불변을 확인했다.
> 표기: **[관찰]** = 샘플에서 직접 확인, **[검증 필요]** = 샘플만으로 확정 불가(업무 확인 또는 Windows Excel 필요).
> 상세 수치와 실험 결과는 `TEMPLATE-ANALYSIS.md`, 셀 단위 매핑은 `FIELD-MAPPING.md`, 미확정 항목은 `OPEN-QUESTIONS.md`.
> 문서와 샘플이 다르면 **샘플을 근거**로 하며, 샘플은 대청교 1개월분뿐이다. 다른 사업·월에 일반화하지 않는다.

> **공개 문서 표기 규칙**: 외부 시스템 고유 식별 문자열(WRIS 영문 헤더, 구분코드, 상수 값)은 중립 이름(`gub_a`, `<구분코드A>` 등)으로 표기한다. 실제 값과의 대응은 비공개 노트(`private/`, git 제외)에만 둔다. `docs/PUBLIC-SAFETY.md` 참조.

## 1. 입력 샘플 (비공개 파일, 저장소 미포함)
- 시트 `월별지급승인` 1개, 사용 범위 `A1:X48`, 병합 22개, 인쇄 설정 없음.
- 헤더 1~2행(2단 병합), 데이터 3~47행(45명), **48행은 합계행**(병합 `A48:E48`, `F48:L48`, 금액·시간 합계). **[관찰]**
- 숨김 열: `B`(너비 0, 헤더 "일치"). `A`는 전 행 `0`. `V` 지급일자는 비어 있고 `W` 지급확인은 전 행 `미처리`, `X` 비고는 비어 있다. **[관찰]** 이 열들의 업무 의미는 **[검증 필요]**이며 지급 대상자 필터에 사용하지 않는다.
- 주요 열: `C` 순번, `D` 년월, `E` 성명, `F` 학번, `G` 학과, `H` 사업자등록번호, `I` 활동기관, `J` 근로지, `K` 멘토 인원, `L` 시급, `M` 시간, `N` 기준금액, `O` 재단 장학금 계, `P` 교부금 집행액, `Q` 이자수익 집행액, `R` 대응투자(기본금), `S` 추가금, `T` 은행명, `U` 계좌번호.
- 2단 헤더: `T1:U1`은 "계좌번호" 상위 헤더, 실제 하위 헤더는 `T2` 은행명, `U2` 계좌번호.
- 타입 **[관찰]**: `F` 학번은 **숫자 셀**(8자리), `U` 계좌번호와 `M` 시간은 문자열. 시간 패턴은 `#시간`, `#시간#분` 두 가지.
- 샘플 한정 사실: 모든 행에서 `N == O`, `O == P + Q`, `Q=R=S=0`.

## 2. 출력 샘플 (비공개 파일, 저장소 미포함)

| 시트 | 범위 | 병합 | 수식 | 비고 |
|---|---|---:|---:|---|
| `지급대상자명단(9월)` | A1:Q50 | 14 | 90 | 탭 색 노랑, 자동 필터 `C3:G4` |
| `WINS` | A1:I46 | 0 | 135 | 헤더 1행, 데이터 2~46행 |
| `wins 업로드 결과(2.9)` | A1:V45 | 0 | 0 | **헤더만 있고 데이터 없음**. 출력에서 제외 |
| `WRIS` | A1:J46 | 0 | 180 | 헤더 1행, 데이터 2~46행 |
| `은행코드` | A1:D79 | 0 | 0 | `A`·`B` 동일 은행명, `C` WINS 코드, `D` WRIS 코드 |

### 2.1 지급대상자명단
- 제목 `A1:Q1`, `Q2`에 `*기준 : YYYY.MM.DD`. 헤더 3~4행(세로·가로 병합), 데이터 5~49행, **합계 50행**. **[관찰]**
- 합계 `K50`(시간 합, **문자열** `N시간`)과 `L50`(금액 합)은 **수식이 아닌 값**. 합계 행 배경 `FFE4B1`, 굵은 글씨. **[관찰]**
- `N`, `O`는 은행코드 시트를 조회하는 `VLOOKUP`(범위 `$B$2:…$79` 고정).
- 열 형식: `D` 학번 숫자 + 텍스트 서식(`@`), `P` 계좌 문자열, `I`·`J`·`L` 숫자 `#,##0_ `, `K` 문자열.
- 데이터 행 스타일은 2종(첫 행: 전체 테두리, 이후 행: 상단 테두리 없음). 행 높이는 5~40행 14.1(고정), **41~49행은 높이 미지정(기본 16.5)**. 합계 50행 16.5, 제목 1행 20.25, 2행 12.
- 인쇄: A4 세로, 여백 기본. **Print_Area·Print_Titles·페이지 나누기 없음.** 조건부 서식은 `duplicateValues` 규칙이 **24개 조각 범위로 분절**되어 있고 전체 데이터 범위를 덮지 않는다.
- 이름 정의: 사용자 정의 없음. 숨김 `_FilterDatabase`만 존재.

### 2.2 WINS / WRIS
- 샘플에서 `G/H/I`(WINS), `E/F/G/H`(WRIS)는 명단을 조회하는 **수식**이며 범위는 명단 `$D$5:…$100` 고정 → 수식 방식 유지 시 **최대 96명**. **[관찰]**
- WINS: `A` 상수 `<근로구분명 상수>`, `B` 연도(숫자), `C` 월(숫자 9), `D` 학번(숫자), `E`·`F` 공란.
- WRIS: `A` 상수 `<구분코드A>`, `B` 상수 `<구분코드B>`, `C` 학번(숫자), `D` 성명, `H` = `D`, `I` 적요 문자열, `J` 공란.
- WRIS `H`는 텍스트 서식(`@`) 셀에 들어 있는 수식이다.
- 학번은 명단·WINS·WRIS 모두 숫자 셀 + 텍스트 서식. 계좌번호는 문자열. **[관찰]** 선행 0이 있는 학번은 샘플에 없어 숫자 저장의 영향은 **[검증 필요]**.

### 2.3 은행코드
- 78개 은행. `C`(WINS 코드)는 **37개 공란**, `D`(WRIS 코드)는 공란 0. 은행명 중복 1건. `C`는 숫자/문자열 혼재. **[관찰]**
- 샘플 45명이 쓴 은행 8종은 모두 두 코드가 존재.

## 3. 샘플 간 교차 일치 **[관찰, 샘플 한정]**
- 입력 3~47행 ↔ 명단 5~49행: 매핑된 13개 열 불일치 0건. 순번 일치.
- 금액 합: 입력 행 합 = 입력 합계행 = 명단 행 합 = 명단 `L50` (값은 문서에 기재하지 않음).
- 시간 합: 분 단위로 합산하면 입력 `M48`·명단 `K50`과 일치(시간만 합하면 불일치).
- WINS `D`, WRIS `C`/`D`는 명단과 45행 모두 일치. 학번 중복 0건.

## 4. 패키지 구성 (보존 위험의 근거)
`calcChain.xml`, `printerSettings1~4.bin`(시트별), 공유 수식, 조건부 서식(dxf 124개 이상)이 있다. 차트·피벗·표(Table)·데이터 유효성·시트 보호·머리글/바닥글은 없다. **[관찰]**

## 5. 이전 문서와 달라진 점
| 이전 서술 | 실측 |
|---|---|
| 입력 마지막 행의 성격 확인 필요 | 48행 합계행 |
| 입력 열 `C~U`만 기술 | `A`, `B`(숨김), `V`, `W`, `X` 존재 |
| 출력 합계 행 미기술 | 명단 50행, 값으로 기록(수식 아님) |
| `wins 업로드 결과(2.9)` 과거 기록 | 헤더만 있음 |
| 수식 범위 미기술 | WINS/WRIS 조회 범위 `$100` 고정(최대 96명) |
| 은행코드 "누락 가능" | WINS 코드 공란 37/78, 중복 1건 |
| 학번 "문자열" 전제 | 샘플 셀은 숫자(텍스트 서식) |
| (중간 보고) 인쇄 제목 `$C$3:$G$4` | 숨김 필터 이름. Print_Titles 없음 |
| 출력 파일명에 날짜 없음(REQUIREMENTS) | 샘플 출력명에는 기준일 접미사(`YYYYMMDD`)가 있음 |

## 6. 이 문서의 한계
- Windows Excel에서 열기·재계산·인쇄 미리보기를 확인하지 않았다(Excel/LibreOffice 미설치).
- 마스킹이 불완전할 수 있다: 사업자등록번호·기관명 등이 실제 값으로 보이는 필드가 있다(수치·값은 비공개 노트에만 기록). **공개 저장소에 커밋 금지**, 확인 전까지 재식별 가능 자료로 취급한다.
