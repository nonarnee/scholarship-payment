# 미확인 사항 (근거·영향도)

> 결정된 사항은 `DECISIONS-OPEN.md`. 이 목록은 **임의로 업무 규칙을 확정하지 않은** 항목이다.
> 영향도: **높음** = 잘못 가정하면 잘못된 지급/업로드 실패 또는 설계 변경, **중간** = 일부 출력 오류·재작업, **낮음** = 표기·편의.
> "차단 조건"은 이 항목이 풀리기 전 구현에 착수하면 안 되는 부분.

## 2. 중간

| # | 질문 | 근거 | 영향 |
|---|---|---|---|
| M1 | 입력 `A`,`B`(숨김),`V`,`W`,`X`의 의미 | `A`=0, `W`="미처리"(전 행). 필터 미사용으로 결정됨 | 지급확인 상태가 의미 있으면 지급 제외 규칙 필요 |
| M2 | 시간 합계가 정시간이 아닐 때 표기 | 샘플 합계는 정시간으로 나누어떨어짐. 분 합산은 일치 확인 | `K` 합계 표기 오류 |
| M3 | 명단 합계 행을 값으로 둘지 수식으로 둘지 | 샘플은 값. 문자열 `N시간` 때문에 SUM 수식 불가 | 합계 불일치 위험 낮음(Writer가 재계산·검증) |
| M4 | 명단 `N`,`O` 은행코드를 수식으로 유지할지 값으로 쓸지 | 샘플은 `VLOOKUP`(은행코드 `$B$2:…$79` 고정). 수식은 캐시 없음 | 비 Excel 도구에서 빈 값, 은행 추가 시 범위 초과 |
| M5 | WINS 코드 공란 37/78, 중복 은행명 1건 | 필요 코드 없으면 차단(결정). 표 보완 책임·절차 미정 | 해당 은행 지급자 차단 빈발 가능 |
| M6 | 제목의 학년도·학기, `Q2` 기준일 산출 규칙 | 제목에 `{학년도}학년도 {학기}학기 … ({연}년 {월}월분)` 형태, `Q2` = 다음 달 7일로 보임 | 제목·기준일 오기 |
| M7 | 입력 `R`,`S`(대응투자·추가금)가 0이 아닐 때 | 샘플은 0. 지급금액은 승인금액(`O`) 기준 | 경고 vs 차단 |
| M8 | 입력 `멘토 인원` ↔ 출력 `멘티 인원` 용어 | 값은 동일하게 복사됨(샘플) | 의미 오표기 |
| M9 | 출력 파일명 규칙 | 샘플은 `..._지급명단_{기준일 YYYYMMDD}`, REQUIREMENTS는 `지급명단_{사업코드}_{YYYY}_{MM}.xlsx` | 낮음에 가깝지만 사용자 혼선 |
| M10 | 0명 처리 | 임시: 안내 후 중단 | |
| M11 | 조건부 서식(중복 학번 강조) 유지 범위 | 템플릿 규칙 24개 조각, 전체 미커버 | 방식 B에서 전체 범위 단일 규칙으로 재구성(실험) |
| M12 | 계좌번호가 **숫자 셀**로 들어오면? | 구현 1단계에서 임시로 BLOCK(숫자 셀은 선행 0·하이픈이 이미 사라져 DI-04 검증 불가). 샘플의 계좌는 문자열 | 실제 데이터에 숫자 계좌가 있으면 생성 차단. 허용하려면 사용자 결정 |
| M13 | 시간 표기의 허용 범위 | 임시로 `N시간`, `N시간M분`(M 0~59)만 허용, 공백·소수·`90분`은 BLOCK. 샘플에서 관찰된 두 형태 | 다른 표기가 있으면 차단됨 |
| M14 | 금액 문자열(쉼표·부호·`원`) 허용 여부 | 임시로 숫자만 허용. 샘플의 금액은 숫자 셀 | 문자열 금액이 있으면 차단됨 |

## 4. 아직 검증하지 못한 것 (실험 환경 한계)
- Windows Excel에서 openpyxl 출력물을 열 때 복구 경고 여부, 인쇄 미리보기, 수식 재계산(Excel/LibreOffice 미설치).
- 전산 업로드(WINS, WRIS) 실제 수용 여부.
- 다른 월·다른 사업에서 레이아웃이 동일한지.
