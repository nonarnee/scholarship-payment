## 7. 발견된 위험
- 로컬 `core.hooksPath` 설정과 `.safety/denylist.local.txt`는 **이 PC에만** 있다. 다른 PC에서는 훅 설치와 금지어 재생성이 필요하다. 훅은 `--no-verify`로 우회된다.
- 목표 Python 3.12가 아닌 3.13.3으로 개발 중이다(PyInstaller 호환은 빌드 단계에서 확인).
- **Adapter는 합성 입력으로만 검증했다.** 실제 다운로드 원본과의 구조 일치는 충실도 점검 도구로 확인했지만, 실제 파일에 Adapter를 실행한 결과는 확인하지 않았다(로컬 수동 스모크는 사용자 요청 시).
- 원본의 헤더 문구·병합이 한 칸이라도 바뀌면 Adapter는 전부 차단한다(공백 차이만 허용). 재단이 양식을 바꾸면 사용할 수 없다(OPEN M16).
- `tools/experiments/exp.py`는 템플릿의 시트명·행 번호(5, 50)에 의존한다.
- **3단계 규칙(M18·M19·M20은 2026-11-03 확정, M17·M21 확인 필요)**: 중복 학번 BLOCK · 금액 ≤ 0 BLOCK · 명단 `N/O` 은행코드 값 기록 · 기준일 = 작성일(확정)  · 출력 파일명/접미 · 은행코드 셀 타입 유지.
- **실제 템플릿**: 자동 테스트는 합성 템플릿으로만 한다. 로컬 스모크에서 실제 템플릿은 정책(제외 시트 이름, WRIS 머리글)을 맞추면 통과했다(위 표). 정책이 다르면 `TEMPLATE_LAYOUT`으로 차단되며 의도된 동작이다. 실제 머리글·상수는 외부 설정으로 주입해야 하지만 **주입 파일 형식은 아직 없다**(`OutputPolicy` 객체까지만).
- 출력 xlsx는 openpyxl이 쓴다: `printerSettings`·`calcChain`·수식 캐시 소실(FP-11 허용 손실). 조건부 서식은 템플릿에 있는 시트에서만 단일 범위 규칙으로 재작성하며 없는 시트에는 만들지 않는다.
- **임시 규칙(사용자 확인 필요)**: ① 계좌번호가 숫자 셀이면 BLOCK(선행 0·하이픈 검증 불가) ② 시간 표기는 `N시간`/`N시간M분`(M 0~59, 공백·소수 불허)만 허용 ③ 금액 문자열은 숫자만 허용(쉼표·부호 불허). 실제 데이터에서 이 표기가 아닌 값이 나오면 차단된다 — `OPEN-QUESTIONS.md` M12~M14.
