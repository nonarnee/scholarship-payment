장학금 지급명단 변환 — 설치·실행 안내
=====================================

※ 이 폴더는 '배포 후보(rc)' 빌드입니다. 정식 배포 전 학교 PC 검증이 끝나지 않았습니다.
   실제 업무에 쓰기 전에 배포 담당자의 안내를 받으세요.

1. 이 프로그램은
------------------
한국장학재단 월별지급승인 엑셀(.xlsx)을 대학 표준 지급명단 엑셀(지급대상자명단·WINS·WRIS)로 변환합니다.
지원 사업: 대청교, 다문화·탈북학생 멘토링, AI멘토링. 네트워크 기능을 사용하지 않도록 만들었습니다.
(학교 PC에서 실제로 네트워크를 쓰지 않는지는 별도 확인 대상입니다.)

2. 설치 (압축 풀기)
-------------------
- 받은 압축 파일의 **폴더 전체**를 PC의 일반 폴더(예: 문서 폴더 아래)에 풉니다. exe 파일만 따로 옮기면 실행되지 않습니다.
- 네트워크 드라이브나 동기화 폴더(OneDrive 등)보다 PC 안의 폴더를 권장합니다(이 환경들에서의 동작은 아직 확인하지 못했습니다).
- 무결성 확인(선택): 폴더의 SHA256SUMS.txt 와 파일의 해시를 비교합니다.
  PowerShell 예:  Get-FileHash .\ScholarshipPayment-v0.3.0-rc.1.exe -Algorithm SHA256

3. 실행
-------
- 폴더 안의 ScholarshipPayment-v...exe 를 더블클릭합니다.
- Windows가 "PC 보호" / SmartScreen 경고를 띄우면 임의로 실행하지 말고 전산팀의 허용 절차를 따르세요(docs/DISTRIBUTION.md 참고).
- 버전과 라이선스 안내: 화면 오른쪽 아래 '정보' 버튼.

4. 처음 설정 (정책·템플릿)
---------------------------
**정책 파일(.json)과 학교 출력 템플릿(.xlsx)은 이 프로그램에 포함되어 있지 않습니다.** 담당자에게서 따로 받아야 합니다.
화면 오른쪽 위 '고급 설정'에서 사업별로 지정합니다.
- 출력 엑셀 서식 템플릿: 사업별로 학교 양식 파일(.xlsx)을 지정합니다.
- 변환 정책 규칙 파일: 이미 있으면 지정하고, 없으면 '새 정책 만들기'로 만듭니다(근무구분명·구분코드 등은 담당자에게 확인).
- 기본 결과 저장 폴더: 지정하면 다음부터 자동으로 채워집니다(비워 두면 변환할 때마다 선택).
다음 위치에 파일을 두면 프로그램이 자동으로 찾습니다(사업 코드: daechung / multicultural / ai).
  1) 이 exe 가 있는 폴더:      policy_<사업코드>.json , template_<사업코드>.xlsx
  2) %APPDATA%\ScholarshipPayment 폴더 (같은 파일 이름)
'고급 설정'에서 직접 지정한 경로가 있으면 그것이 우선입니다.

5. 사용자 설정 파일
-------------------
위치: %APPDATA%\ScholarshipPayment\settings.json
저장하는 것: 마지막으로 고른 사업, 사업별 템플릿 경로·정책 경로·기본 저장 폴더 경로.
저장하지 않는 것: 원본 파일 경로, 비밀번호, 기준일, 학생 정보.
설정 파일이 손상되면 settings.json.bak 으로 보존하고 기본값으로 시작합니다(기존 백업은 덮어쓰지 않습니다).
초기 상태로 돌리려면 프로그램을 닫고 settings.json 을 이름 변경하거나 삭제하세요(정책·템플릿 파일은 지워지지 않습니다).

6. 사용 순서
------------
1) 파일 선택: 사업, 기준일(기본값 오늘), 재단 원본 엑셀, 결과 저장 폴더를 고릅니다. 엑셀(.xlsx) 한 개만 사용할 수 있습니다.
2) 지급내역 확인: 읽기 전용 확인입니다(지급연월·대상자 수·금액 합계, 오류·경고·참고). 이 단계에서는 파일을 만들지 않습니다.
   암호가 걸린 원본이면 비밀번호를 묻습니다(최대 3번, 비밀번호는 저장하지 않습니다).
3) 결과 생성: '지급명단 생성'을 누르면 저장하고, 저장 전에 만든 파일을 다시 읽어 확인합니다. 같은 이름의 파일이 있으면 덮어쓰지 않고 새 이름으로 저장합니다.

7. 알려진 한계 (꼭 읽어 주세요)
-------------------------------
- 파일을 저장하는 중에는 창을 닫을 수 없습니다. 저장이 끝난 뒤 닫을 수 있습니다.
- 저장 중에 작업 관리자로 강제 종료하거나 전원이 꺼지는 등 **비정상 종료**가 되면 결과 폴더에 이름이 ".~"로 시작하는 임시 .xlsx 파일이 남을 수 있습니다.
  이런 파일은 프로그램이 **자동으로 삭제하지 않습니다.** 다음 변환 뒤 결과 화면에 개수만 알려 주며, 내용을 확인한 뒤 직접 지우세요.
  비정상 종료 상황에서 안전하게 정리된다고 보장하지 않습니다.
- 미리보기 뒤에 원본·템플릿·정책 파일이 바뀌면 파일을 만들지 않고 다시 확인하라고 안내합니다(자동으로 다시 만들지 않습니다).
- 실제 Windows Excel에서의 열기·인쇄·업로드 호환성, 학교 PC 환경(Defender, 네트워크 드라이브 등)은 배포 전 검증 대상입니다.

8. 이전 버전으로 되돌리기
-------------------------
- 새 버전 폴더를 풀기 전에 현재 사용 중인 폴더를 지우지 말고 이름만 바꿔 보관하세요(예: ScholarshipPayment_이전).
- 문제가 있으면 새 폴더를 닫고, 보관해 둔 이전 폴더의 exe 를 실행합니다. 같은 배포에 들어 있는 legacy(Tkinter) 폴더도 같은 변환 엔진을 쓰는 이전 방식의 화면입니다.
- 이전 화면(legacy)은 settings.json 을 쓰지 않으므로 설정 파일 때문에 되돌리기가 막히지 않습니다. 이미 만든 결과 파일은 그대로 남습니다.
- 되돌릴 때는 어떤 버전에서 어떤 문제가 있었는지(화면, 단계, 오류 코드)를 배포 담당자에게 알려 주세요. 학생 정보·계좌·실제 파일 이름은 적지 마세요.

9. 라이선스
-----------
이 프로그램은 Qt(PySide6)를 포함한 오픈소스 구성 요소를 사용합니다. 라이선스 전문과 고지는 LICENSES 폴더에 있습니다(LICENSES\README-LICENSES.txt 부터 읽으세요).
